# The Bone Core 🦴

تطبيق ذكي مخصص لتحسين استقامة الجسد وصحة العظام باستخدام تقنيات TENS والحرارة العلاجية.

## ما هو التطبيق؟
هو مساعدك الشخصي الذي يجمع بين التكنولوجيا والأساليب الطبيعية لضمان:
- ⚡ **جلسات TENS:** لتخفيف الألم وارتخاء العضلات.
- 🌡️ **علاج حراري:** للتحكم في آلام الفقرات والمفاصل.
- 📚 **مرجع شامل:** نصائح يومية لتغذية العظام ونمط الحياة الصحي.

## كيف تستخدمه؟
1. تأكد من اتصال هاتفك بالجهاز عبر البلوتوث (📶).
2. اختر الوضع المناسب لجلسة العلاج (مكتب، رياضة، راحة).
3. اضبط مستوى النبضات والحرارة وابدأ الجلسة.
4. اتبع النصائح اليومية المذكورة في تبويب "المرجع" لضمان أفضل النتائج.

## التقنيات المستخدمة
- React Native
- Expo
- React Native SVG (للرسم البياني)
- Community Slider (للتحكم في المستويات)
